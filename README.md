# Automated Multi-Node Monitoring Cluster (Ansible + Docker)

Автоматизированная система мониторинга для кластера из 3-х серверов на базе Ubuntu, развернутая полностью через **Ansible** и упакованная в **Docker**.

## Техологический стек
* **Оркестрация / Конфигурация:** Ansible (ролевая структура)
* **Контейнеризация:** Docker & Docker Compose
* **Сбор метрик:** Prometheus & Node Exporter
* **Визуализация:** Grafana (Дашборд №1860)
* **Шаблонизация:** Jinja2 (динамическая сборка конфигов)

## Что было реализовано в проекте:
1. **Инфраструктура как код (IaC):** Архитектура разбита на переиспользуемые роли (`docker`, `node_exporter`, `monitoring_stack`). Деплоится одной командой.
2. **Обход геоблокировок Docker Hub:** В роль автоматизации Docker внедрено автоматическое распределение локальных зеркал реестров (Yandex Cloud / Timeweb), что гарантирует бесперебойный пулл образов на территории РФ.
3. **Динамический сбор хостов (Jinja2):** Конфигурация Prometheus генерируется динамически на основе инвентаря Ansible (`hosts.ini`), автоматически собирая IP-адреса всех целевых машин в один пул для метрик.
4. **Безопасность:** Настройка беспарольного SSH-доступа по ключам и менеджмент прав директорий контейнеров (0777/chown под встроенных пользователей Докера).
